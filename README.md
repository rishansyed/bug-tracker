# 🐞 Bug Tracker (C Project)

## 📌 Description
This is a simple Bug Tracker built using C language.
It allows users to add and view bugs.

## ⚙️ Features
- Add new bugs
- View all bugs
- Stores data in a file

## 🛠️ Technologies
- C Language
- File Handling

## ▶️ How to Run
1. Compile:
   gcc main.c -o bugtracker
2. Run:
   ./bugtracker

## 📁 Files
- main.c
- bugs.txt
